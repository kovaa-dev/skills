# Security Policy

Agent skills can influence tool use, repository changes, and software delivery workflows. Treat changes to skill instructions as security-sensitive documentation changes.

## Supported versions

| Version | Supported |
| --- | --- |
| `0.1.x` | Yes |

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue.

Use GitHub Private Vulnerability Reporting or the repository's private security advisory channel. Include:

- the affected skill and file;
- the risky instruction or behavior;
- a realistic impact scenario;
- the agent or installer involved;
- a suggested mitigation, if available.

If no private reporting channel is available, contact the repository maintainer privately before public disclosure.

Never include credentials, private repository content, personal data, or other secrets in a report.
